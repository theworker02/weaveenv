# weaveenv

Weave lightweight env statistics from stdin samples.

**Site:** https://theworker02.github.io/weaveenv/

## Install / run

```bash
git clone https://github.com/theworker02/weaveenv.git
cd weaveenv
node src/cli.js
node --test
```
